# Success Metrics

+## Measures

- Review-to-action: percentage of native comments linked to a correction when relevant.
- Intake quality: OCR text completeness, crop alignment pass rate, needs-review rate, per-batch processing p50/p95.
- Production closure: count/time to Fixed, separate from feasibility and approval.
- Reliability: failed/duplicate job ratio, retry recovery rate, no-lost-remark incidents.
- Safety: blocked cross-scope attempts, share revocation effectiveness, critical security defects open.

Baseline is collected after Phase 20; targets are set from observed studio workload rather than invented guarantees.
