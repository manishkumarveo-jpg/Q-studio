# Customer Journey

+## Journey

1. Owner deploys, provides secret bootstrap credentials, and signs in.
2. Admin adds studio users and a producer creates a project/show/episode.
3. Producer uploads asset versions or imports reviewer screenshots.
4. Reviewer comments in context; external source screenshots enter a verification queue.
5. Producer triages correction records; artists resolve tracked work.
6. Producer exports current, version-aware correction state and requests approval.
7. Owner audits activity and retires data under retention policy.
