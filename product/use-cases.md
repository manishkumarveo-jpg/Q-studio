# Use Cases

+## Use cases

UC-01 Native media review: create a version-bound frame/range comment and reply thread.

UC-02 Episode QC: filter an episode correction sheet, mark feasible/not feasible, assign, remark, and mark fixed.

UC-03 Screenshot intake: upload multiple external review screenshots, independently retry failed items, verify uncertain extraction, and append late notes.

UC-04 Controlled sharing: create a revocable link limited to selected assets and explicitly granted actions.

UC-05 Administration: create/disable a user and revoke their sessions without needing an external identity provider.
