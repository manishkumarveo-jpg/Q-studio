# Integrations

+## Integration boundary

R2 is a first-party Cloudflare storage binding, not an external end-user drive. The only production integration planned for early releases is Cloudflare platform infrastructure. Premiere, Resolve, Final Cut, Camera-to-Cloud, external transfer clients, hosted transcription, and Drive migration are UI/configuration placeholders marked Not Connected until real adapters, security review, and compatibility tests exist. No hosted LLM integration is required or planned.
