# Ui Guidelines

+## UI truthfulness rules

One primary action per view; show progressive disclosure for advanced controls. Do not use fake success toasts. Any local seed/demo behavior says “Demo data” or “Simulated”; unavailable preview uses “Preview unavailable”; unimplemented integrations say “Not connected.” Destructive actions require specific confirmation and explain preservation rules. Mutations show Saving, Saved, Error or Offline rather than silently discarding changes.
