# Design System

+## Design tokens

Dark foundation: near-black canvas, elevated slate panels, high-contrast ink, violet primary, cyan focus, amber warning, emerald positive, rose destructive. Type: 12–14px dense metadata, 14–16px body, 20–28px page headings. All interactive states have focus-visible treatment, disabled styling, and semantic—not color-only—status labels. Components use an 8px rhythm, 8–12px radii, and minimum 44px touch targets where space permits.
