# Ux Test Cases

+## UX cases

- TC-UX-001: Tab through shell, menus and dialog; focus order/return is predictable.
- TC-UX-002: Collapse sidebar then use current-page controls without layout overlap.
- TC-UX-003: Filter QC table then use Up/Down/P/N/F/R; only visible selected rows change.
- TC-UX-004: Enter a text area then press P/N/F/R; no global shortcut fires.
- TC-UX-005: Screen reader receives meaningful labels for media controls, status toggles and crop lightbox.
- TC-UX-006: A simulated transfer/share/integration states its simulated status before action.
