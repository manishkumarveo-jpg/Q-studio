# Accessibility

+## Accessibility

Target WCAG-relevant keyboard, focus, name/role/value and contrast paths. Use semantic buttons/inputs/tables; associate error text; trap and restore focus for modal dialogs; provide visible focus; label icon buttons; respect reduced motion; do not encode Possible/Not Possible only by green/red. QC keyboard shortcuts are disabled while typing in inputs, textarea, or contenteditable. Test with axe plus manual keyboard and screen-reader smoke journeys.
