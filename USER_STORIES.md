# USER STORIES

+## Core stories

- US-OWN-001: As an owner, I bootstrap exactly one owner account without exposing credentials.
- US-PROD-001: As a producer, I can create a show episode and see a chronologically sorted correction sheet.
- US-PROD-002: As a producer, I can append late screenshots without changing existing correction statuses, remarks, assignees, or IDs.
- US-REV-001: As a reviewer, I can leave a timestamp or range comment on the exact asset version I reviewed.
- US-ART-001: As an editor/animator, I can filter my assigned corrections, update a remark, and mark work fixed independently of review feasibility.
- US-CLIENT-001: As a client, I can view only the media and actions granted on a valid, unrevoked review link.
- US-ADMIN-001: As an admin, I can create members, change roles, disable an account, revoke sessions, and inspect relevant audit activity.

Acceptance criteria appear in [ACCEPTANCE_CRITERIA.md](ACCEPTANCE_CRITERIA.md).
