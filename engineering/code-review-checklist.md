# Code Review Checklist

+## Review checklist

- Requirement/acceptance/test IDs linked.
- Server-side authorization and schema validation present.
- No secret, token, raw media or PII logging.
- Version/QC/late-note identities preserved.
- Errors, idempotency, race and offline states considered.
- Keyboard/accessibility and mobile state reviewed.
- Docs/changelog/test results accurately updated.
