# PRD

+## Vision

A premium, workflow-dense studio tool for reviewing media and turning feedback into accountable production corrections without retyping native comments or pretending OCR is perfect.

## Goals

1. Make feedback precise: timestamps, frame/range comments, annotations, threads, versions, approvals.
2. Make external screenshot notes reviewable structured data: originals, crops, OCR confidence, editable text, deterministic sort.
3. Make production progress visible: departments, possible/not possible, fixed status, assignees, remarks, history, exports.
4. Keep private media private through server-enforced roles and scoped capabilities.

## Primary success signals

A producer can produce a correction sheet without manual transcription; an artist can find, update, and resolve assigned work; a reviewer can leave version-correct feedback; every sensitive read/write is auditable. See [product/success-metrics.md](product/success-metrics.md).

## Release rule

A capability is real only after its API, persistence, authorization, tests, and operator documentation ship. Otherwise UI uses a visible Demo Only or Simulated label.
